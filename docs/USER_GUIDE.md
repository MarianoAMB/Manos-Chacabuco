# Guía de uso — Manos Chacabuco

## Para empezar

La aplicación guarda el trabajo en este dispositivo y también funciona sin
Internet. Desde **Inicio** podés entrar a cada sección o usar los accesos para
crear una materia prima, un producto o un presupuesto.

Si la aplicación está vacía, el orden recomendado es:

1. Cargar las materias primas que comprás.
2. Crear los productos y decir cuánto usa cada uno.
3. Armar presupuestos o listas de precios.

No es un recorrido obligatorio: podés volver y completar información cuando la
necesites.

## Materias primas

Acá se guardan cordones, cueros, cierres, accesorios y demás insumos. Indicá la
presentación comprada, su precio y la unidad que usás al fabricar. Si un mismo
material tiene colores o variantes con precios distintos, cargalos dentro de la
misma materia prima.

**Desactivar** conserva la información pero evita usarla en trabajos nuevos.
**Eliminar** la quita del listado cuando no está siendo utilizada.

## Productos

Cada producto reúne sus medidas, foto opcional, materias primas y reglas de
precio. El costo se actualiza cuando cambia el precio de una materia prima. El
precio mayorista usa el multiplicador del producto y el minorista aplica además
el porcentaje configurado.

Usá **Ver detalle del cálculo** para revisar de dónde sale cada importe.

## Presupuestos

Un presupuesto puede incluir varios productos, cantidades, personalizaciones y
ajustes. La fecha de vencimiento se calcula desde los días de validez.

Cuando lo guardás, conserva los precios de ese momento. Los cambios posteriores
de materias primas o productos no lo modifican. Usá **Recalcular con precios
actuales** solamente cuando quieras actualizarlo de manera explícita.

## Calculadora

Podés calcular a partir de un producto existente o estimar una pieza nueva. La
pantalla prioriza el material estimado, el costo y los precios sugeridos. Si no
hay referencias suficientes, completá el consumo manualmente; la aplicación no
inventa un resultado.

## Listas de precios

Elegí lista minorista o mayorista, seleccioná productos y revisá la vista previa.
Al exportar podés elegir:

- **Con fotos:** catálogo visual.
- **Sin fotos:** lista editorial de dos columnas.

Después elegí PDF o imágenes. En Android también podés abrir el menú para
compartir. En Windows se guarda el resultado y podés abrir el archivo o su
carpeta.

Las listas nunca muestran costos, hilo, desperdicio, multiplicadores ni notas
internas.

## Sincronización

En **Configuración → Sincronización** podés conectar una cuenta de Google para
mantener los mismos datos en Android y Windows. Usá la misma cuenta en ambos
equipos. La app muestra todos los dispositivos vinculados, su última
sincronización y cuántos productos, materias primas y presupuestos tiene cada
uno. En el dispositivo actual podés tocar **Cambiar nombre** y poner, por
ejemplo, “Celular de Laura” o “PC del taller”. Si una misma información fue
editada de forma diferente en varios dispositivos, verás cada versión con su
equipo y fecha para elegir cuál conservar.

## Si no hay Internet

Seguí trabajando normalmente. Todo se guarda primero en el dispositivo. Cuando
vuelva la conexión, los cambios pendientes se sincronizarán. No hace falta
volver a importar la planilla ni rehacer el trabajo.
